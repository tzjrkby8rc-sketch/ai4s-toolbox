# AI4S 科研赋能工具箱 · 落地页

面向科学家 / 教授 / 高校教师的 AI4S（AI for Science）营销工具箱。

## 页面导航

| 页面 | 说明 |
|------|------|
| `index.html` | 🚀 学科门户（入口） |
| `life.html` | 🧬 生命科学（主推）—— 蛋白/药物/基因/影像 |
| `material.html` | ⚛️ 物质科学 —— 计算化学/新材料/结构解析 |
| `engineering.html` | ⚙️ 工程技术 —— 光学/工业优化/湿实验 |
| `earth.html` | 🌍 地球环境 —— 气象/海洋/地震 |
| `math.html` | 🔢 数学量子 —— 数学推理/高性能计算 |
| `cross.html` | 🔀 交叉学科 —— 社科/语音文本/大模型 |
| `home.html` | 🧭 通用诊断 —— 政策雷达 + 能力诊断 + 工具导航 |

## 核心功能

- **政策雷达**：9 主政策 + 4 标杆，申报窗口倒计时，学科匹配
- **能力诊断**：3-4 问交互，生成个性化《AI4S 落地路径报告》
- **工具选型导航**：137 项资产（12 智能体 / 33 工具链 / 92 模型）
- **留资转化**：诊断报告 → 邮箱留资 → 发送完整报告

## 数据来源

智爱赛思（aisaisi.net）公开知识库。政策以官方通知为准。

cd 落地页 && python3 -m http.server 8899
