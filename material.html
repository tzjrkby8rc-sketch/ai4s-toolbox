1AI4S 使用范畴

AI 在材料化学领域能做什么--四个核心方向

计算化学

LLM 副驾驶(MolPilot)接管计算化学全流程,自动生成科学假设;ECNU-ChemGPT2 化学大模型支持逆合成路线规划;反应/性质/逆合成预测一站式。

新材料发现

主动学习(Bgolearn)+ 生成模型,少样本高效发现新材料;SciToolAgent-Mat 对接 Materials Project,电池/MOF 评估开箱即用;LASP 神经网络势函数大尺度原子模拟。

结构与解析

X 射线衍射 -> 电子密度图 -> 原子模型精修,晶体结构解析加速器 + DPA 深度势能原子模拟,结构解析周期数量级缩短。

性质预测

燧人系列模型预测热膨胀/临界密度/蒸气压/粘度等材料物性,替代昂贵实验测定。

2基础使用技巧

从零上手--核心工具的使用路径

MolPilot

计算化学副驾驶:输入研究问题 -> 自动生成假设 -> 调用结构互转/性质/反应预测/逆合成工具 -> 返回完整分析。

Bgolearn

国产开源贝叶斯优化:npx 启动 -> 输入已有实验数据(少样本)-> 主动学习推荐下一组实验参数,替代盲目 DOE。

SciToolAgent-Mat

材料计算工具:MOF 解析 / Materials Project 对接 / 电池评估,72.4k 调用,Web 端即用。

3科研设计指南

如何设计 AI 辅助的材料化学研究--分阶段要点

假设与检索

ECNU-ChemGPT2 生成逆合成路线假设;Origene-PubChem 查全球最大开放化学库定位已知化合物。

计算筛选

实验验证

计算筛选 top 候选 -> 湿实验合成验证 -> 数据回流再训练 Bgolearn,迭代优化。

结构表征

晶体结构解析加速器处理 XRD 数据;DPA 深度势能模拟确认原子级结构。
